# My Spanish Adventure Guide

Jadę do Hiszpani od 20-29 sierpnia, chcę zaprojektować taką apkę przewodnik stricte pod ten wyjazd z zakładką na każdy dzień, rozmówkami, podstawowymi zwrotami, informacjami o hiszpanii, tradycji, kulturze, o tym co danego dnia się dzieje w Hiszpanii + pogoda na miejscu oraz miejsca, gdzie warto się zatrzymać. Przygotuj makiety w TypeScript w stylu minimal Fancy Tech sygnowane logiem NullPointerStudio oraz dokumentację pełną dla Claude by bezproblemowo mógł zaimplementować makietę. 20-22 września Malaga, 22-26 września Tolox, 26-29 września Estepona
